Purpose and boundaries
This is a browser-local screening prototype for WCAG 2.2 SC 2.3.1. It calculates relative luminance from captured, reduced-resolution sRGB pixels, counts opposing luminance transitions, and uses an experimental accumulated color-excursion model for red candidates. Physical flash area, viewing geometry, fine-pattern exceptions, HDR coverage, and complete red conformance are not established. Evaluate whether the tool communicates these limits consistently and avoids a false pass or safety claim. Verify definitions against current primary W3C guidance.
